# Task 2 - Customer Segmentation

## Objective
Perform customer segmentation using data analysis and clustering techniques to identify different customer groups based on their purchasing behavior.

## Tools & Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow
- Data Loading
- Data Preprocessing
- Exploratory Data Analysis
- Feature Selection
- Customer Segmentation
- K-Means Clustering
- Cluster Visualization
- Insights and Analysis

## Key Outcome
Customers were grouped into different segments based on their purchasing behavior using K-Means clustering. The analysis helps understand customer groups and their characteristics.
